Functional Responses

PhysiologicallyBasedDemographicModels.HollingTypeII — Type
HollingTypeII(a, h)

Holling Type II functional response (disc equation): f(N) = a × N / (1 + a × h × N)

  • a: attack rate (area searched per predator per time)
  • h: handling time per prey item
PhysiologicallyBasedDemographicModels.HollingTypeIII — Type
HollingTypeIII(a_max, b, h)

Holling Type III (sigmoid) functional response: f(N) = a_max × N² / (b² + N²) / (1 + a_max × h × N² / (b² + N²))

Simplified form: f(N) = a_max × N² / (b² + N²) × 1/(1 + h × ...)

PhysiologicallyBasedDemographicModels.functional_response — Function
functional_response(fr, prey_density)

Compute per-predator consumption rate from functional response.

Trophic Web

PhysiologicallyBasedDemographicModels.TrophicLink — Type
TrophicLink(predator_name, prey_name, response, conversion_efficiency)

A directed trophic link between two populations. conversion_efficiency is the fraction of consumed prey biomass converted to predator biomass.

PhysiologicallyBasedDemographicModels.TrophicLevel — Type
TrophicLevel{T<:Real}

Simplified aggregate-biomass parameterization of one trophic level for management optimization. This is NOT a full distributed-delay population; it captures only the key mass-balance parameters needed for the discrete-time optimal control formulation.

Fields

  • name::Symbol — level identifier (e.g., :plant, :herbivore, :predator)
  • demand_rate::T — per-capita demand rate (d)
  • fr::AbstractFunctionalResponse — functional response for resource acquisition
  • resp::Q10Respiration{T} — respiration model
  • conversion_efficiency::T — assimilation efficiency (ε)
  • intrinsic_rate::T — intrinsic growth rate (only for basal resource; 0 otherwise)
  • carrying_capacity::T — carrying capacity (only for basal resource; Inf otherwise)
PhysiologicallyBasedDemographicModels.TrophicWeb — Type
TrophicWeb(links)

A collection of trophic links defining a food web.

PhysiologicallyBasedDemographicModels.add_link! — Function
add_link!(web::TrophicWeb, link::TrophicLink) -> TrophicWeb

Append a TrophicLink to web in place and return the web.

PhysiologicallyBasedDemographicModels.find_links — Function
find_links(web, predator_name)

Find all trophic links where the given species is the predator.

PhysiologicallyBasedDemographicModels.find_predators — Function
find_predators(web, prey_name)

Find all trophic links where the given species is the prey.

Sterile Insect Technique

PhysiologicallyBasedDemographicModels.SITRelease — Type
SITRelease(sterile_males, competitiveness, release_interval)

Sterile insect technique release parameters.

  • sterile_males: number released per event
  • competitiveness: mating competitiveness relative to wild males (0-1)
  • release_interval: days between releases
PhysiologicallyBasedDemographicModels.fertile_mating_fraction — Function
fertile_mating_fraction(wild_males, sit::SITRelease, day)

Compute the fraction of matings that are fertile given SIT releases.
