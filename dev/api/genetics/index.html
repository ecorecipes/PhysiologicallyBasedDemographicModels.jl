Genetics

Genotype Models

PhysiologicallyBasedDemographicModels.AbstractGenotypeModel — Type
AbstractGenotypeModel

Supertype for genetic tracking models.

PhysiologicallyBasedDemographicModels.DialleleicLocus — Type
DialleleicLocus(R, dominance)

A single diallelic locus with allele frequency R (resistant) and 1-R (susceptible). dominance ∈ [0,1]: 0 = fully recessive resistance, 0.5 = codominant, 1 = fully dominant.

PhysiologicallyBasedDemographicModels.genotype_frequencies — Function
genotype_frequencies(locus::DialleleicLocus)

Return Hardy-Weinberg genotype frequencies (SS, SR, RR).

genotype_frequencies(R::Real)

Return Hardy-Weinberg genotype frequencies from allele frequency R.

PhysiologicallyBasedDemographicModels.allele_frequency_from_adults — Function
allele_frequency_from_adults(n_SS, n_SR, n_RR)

Compute resistance allele frequency from genotype counts.

Selection

PhysiologicallyBasedDemographicModels.GenotypeFitness — Type
GenotypeFitness(w_SS, w_SR, w_RR)

Relative fitness values for each genotype.

PhysiologicallyBasedDemographicModels.selection_step! — Function
selection_step!(locus, fitness)

Update allele frequency after one generation of selection. Uses the standard population genetics recursion.

Dose-Response

PhysiologicallyBasedDemographicModels.DoseResponse — Type
DoseResponse(ld50, slope)

Probit/logistic dose-response curve. ld50 is the dose killing 50% of susceptible individuals; slope controls steepness.

PhysiologicallyBasedDemographicModels.mortality_probability — Function
mortality_probability(dr::DoseResponse, dose)

Compute mortality probability at a given dose. Uses a logistic model: P(death) = 1 / (1 + (ld50/dose)^slope).

Resistance Management

PhysiologicallyBasedDemographicModels.refuge_dilution — Function
refuge_dilution(R_field, R_refuge, refuge_fraction)

Dilute resistance allele frequency by gene flow from a refuge.

PhysiologicallyBasedDemographicModels.TwoLocusResistance — Type
TwoLocusResistance(locus1, locus2)

Independent two-locus resistance model (e.g., Cry1Ac + Cry2Ab).

PhysiologicallyBasedDemographicModels.probability_fully_resistant — Function
probability_fully_resistant(tlr::TwoLocusResistance)

Probability of being homozygous resistant at both loci (independent).
