Epidemiology

SIR Disease

PhysiologicallyBasedDemographicModels.AbstractDiseaseModel — Type
AbstractDiseaseModel

Supertype for compartmental disease models in the epidemiology module (e.g. SIRDisease, VectorBorneDisease). Concrete subtypes are advanced via step_disease! / step_vector_disease!.

PhysiologicallyBasedDemographicModels.SIRDisease — Type
SIRDisease(β, γ, μ_d)

Simple SIR disease model with:

  • β: transmission rate (per contact per day)
  • γ: recovery rate (per day)
  • μ_d: disease-induced mortality rate (per day)
PhysiologicallyBasedDemographicModels.DiseaseState — Type
DiseaseState(S, I, R, D)

Compartmental disease state: Susceptible, Infected, Recovered, Dead-from-disease.

PhysiologicallyBasedDemographicModels.total_alive — Function
total_alive(ds::DiseaseState) -> Real

Sum of S + I + R (excludes disease-induced deaths D).

PhysiologicallyBasedDemographicModels.prevalence — Function
prevalence(ds::DiseaseState) -> Real

Fraction of the alive sub-population currently infected: I / (S+I+R). Returns 0.0 if the alive sub-population is empty.

PhysiologicallyBasedDemographicModels.step_disease! — Function
step_disease!(state, disease, contact_rate; dt=1.0)

Advance disease dynamics by one time step. Returns named tuple of new infections, recoveries, and deaths.

PhysiologicallyBasedDemographicModels.R0 — Function
R0(disease::SIRDisease, contact_rate)

Basic reproduction number for SIR model.

Vector-Borne Disease

PhysiologicallyBasedDemographicModels.VectorBorneDisease — Type
VectorBorneDisease(β_vh, β_hv, γ_h, μ_h, extrinsic_incubation)

Vector-borne disease transmission model.

  • β_vh: vector-to-host transmission probability per bite
  • β_hv: host-to-vector transmission probability per bite
  • γ_h: host recovery rate
  • μ_h: host disease-induced mortality
  • extrinsic_incubation: days for pathogen to develop in vector
PhysiologicallyBasedDemographicModels.VectorState — Type
VectorState(S, E, I)

Vector (insect) disease state: Susceptible, Exposed (incubating), Infectious.

PhysiologicallyBasedDemographicModels.total_vectors — Function
total_vectors(vs::VectorState) -> Real

Total vector population S + E + I for a VectorState.

PhysiologicallyBasedDemographicModels.step_vector_disease! — Function
step_vector_disease!(host_state, vector_state, disease, bite_rate; dt=1.0)

Advance vector-borne disease dynamics for one time step.
