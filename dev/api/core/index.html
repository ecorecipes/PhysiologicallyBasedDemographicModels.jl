Core Abstractions (StructuredPopulationCore)

Type Hierarchy

StructuredPopulationCore.AbstractProjectionSolution — Type
AbstractProjectionSolution

Supertype for projection model solutions. Subtypes must have fields:

  • t: time steps
  • u: population states
  • kernel_matrices: materialized kernel(s)
  • eigenanalysis: named tuple (lambda, stable_dist, repro_value) or nothing
  • retcode: Symbol
  • lambdas: per-step growth rates
StructuredPopulationCore.AbstractStateDomain — Type
AbstractStateDomain

Supertype for shared domain descriptors over which state variables are defined.

StructuredPopulationCore.ContinuousDomain — Type
ContinuousDomain{T<:Real}

Represents a continuous state variable domain discretized via the midpoint rule.

The domain [lower, upper] is divided into n_meshpoints bins. Meshpoints are the midpoints of each bin.

StructuredPopulationCore.DiscreteDomain — Type
DiscreteDomain

Represents a discrete state variable with named levels.

StructuredPopulationCore.AbstractStateSemantics — Type
AbstractStateSemantics

Supertype for state-space semantics traits.

StructuredPopulationCore.ContinuousState — Type
ContinuousState

Continuum-valued or discretized-from-continuum state space.

StructuredPopulationCore.FiniteState — Type
FiniteState

Finite-dimensional or explicitly enumerated state space.

StructuredPopulationCore.GeneralContinuousState — Type
GeneralContinuousState

Alias of GeneralIPM. Use this name when writing code at the generic multi-state continuous-state level.

StructuredPopulationCore.SimpleContinuousState — Type
SimpleContinuousState

Alias of SimpleIPM. Use this name when writing code at the generic continuous-state-structure level (e.g., for finite-element or non-IPM continuous-state schemes).

StructuredPopulationCore.AbstractTimeSemantics — Type
AbstractTimeSemantics

Supertype for time-semantics traits.

StructuredPopulationCore.ContinuousTime — Type
ContinuousTime

Infinitesimal-generator semantics over continuous time.

StructuredPopulationCore.DiscreteTime — Type
DiscreteTime

One-step update semantics over a discrete clock.

StructuredPopulationCore.AbstractContinuousStateStructure — Type
AbstractContinuousStateStructure

Shared supertype for continuous-state model structures. This is used by both discrete-time integral projection models and the forthcoming continuous-state continuous-time backends.

StructuredPopulationCore.AbstractIPMStructure — Type
AbstractIPMStructure

Compatibility supertype for the existing integral projection model structure names. It remains available as part of the shared abstraction layer so current IPM code can keep its API while new packages dispatch on the more neutral AbstractContinuousStateStructure.

StructuredPopulationCore.SimpleIPM — Type
SimpleIPM

Single continuous-state structure.

StructuredPopulationCore.GeneralIPM — Type
GeneralIPM

Multi-state or otherwise generalized continuous-state structure.

StructuredPopulationCore.StateBlockLayout — Type
StateBlockLayout(names, sizes)

Describe a flattened state vector made of named contiguous blocks.

names[i] names the block occupying sizes[i] consecutive entries.

StructuredPopulationCore.blocknames — Function
blocknames(layout)

Return the block names in layout order.

StructuredPopulationCore.blockrange — Function
blockrange(layout, name)

Return the contiguous index range for block name.

StructuredPopulationCore.blockranges — Function
blockranges(layout)

Return a dictionary of block ranges keyed by name.

StructuredPopulationCore.bounds — Function
bounds(d::ContinuousDomain)

Return the n_meshpoints + 1 bin edges spanning [lower, upper].

StructuredPopulationCore.meshpoints — Function
meshpoints(d::ContinuousDomain)

Return the midpoints of the n_meshpoints bins spanning [lower, upper].

StructuredPopulationCore.n_states — Function
n_states(d::AbstractStateDomain)

Number of state classes represented by d. For a DiscreteDomain this is the number of named levels; for a ContinuousDomain it is the number of mesh points.

StructuredPopulationCore.step_size — Function
step_size(d::ContinuousDomain)

Width of each discretization bin: (upper - lower) / n_meshpoints.

StructuredPopulationCore.combine_state — Function
combine_state(layout, blocks)

Combine named state blocks back into one flattened state vector.

StructuredPopulationCore.split_state — Function
split_state(state, layout; copy=true)

Split a flattened state vector into named blocks.

When copy=false, the returned dictionary contains views into state.

StructuredPopulationCore.extract_population — Function
extract_population(n_aug::AbstractVector, m::Int)

Extract the current physical population state (first m elements) from an augmented state vector.

Eigen & Demographic Analysis

StructuredPopulationCore.EigenAnalysis — Type
EigenAnalysis

Compute eigendecomposition of the materialized kernel matrix. No iteration is performed; returns asymptotic quantities directly.

StructuredPopulationCore.eigenanalysis_full — Function
eigenanalysis_full(A::AbstractMatrix)

Full eigendecomposition using LinearAlgebra.eigen. Returns a named tuple (lambda, stable_dist, repro_value). Reproductive value is normalized so that dot(v, w) = 1.

StructuredPopulationCore.eigenanalysis_power — Function
eigenanalysis_power(A::AbstractMatrix; maxiter=2000, tol=1e-12)

Compute dominant eigenvalue, stable distribution (right eigenvector), and reproductive value (left eigenvector) via power iteration.

Returns a named tuple (lambda, stable_dist, repro_value). Reproductive value is normalized so that dot(v, w) = 1.

StructuredPopulationCore.lambda — Function
lambda(A::AbstractMatrix)

Dominant eigenvalue of projection matrix A.

lambda(sol::AbstractProjectionSolution; burn_in_frac=0.1)

Dominant eigenvalue from solution. Uses eigenanalysis if available, otherwise computes stochastic growth rate from per-step lambdas.

StructuredPopulationCore.stable_distribution — Function
stable_distribution(A::AbstractMatrix)

Normalized right eigenvector of A (stable stage/size distribution).

stable_distribution(sol::AbstractProjectionSolution)

Stable distribution from solution eigenanalysis, or approximated from final state.

StructuredPopulationCore.reproductive_value — Function
reproductive_value(A::AbstractMatrix)

Normalized left eigenvector of A (reproductive value).

reproductive_value(sol::AbstractProjectionSolution)

Reproductive value from solution eigenanalysis, or computed from kernel matrix.

StructuredPopulationCore.damping_ratio — Function
damping_ratio(A::AbstractMatrix)

Ratio of dominant to subdominant eigenvalue magnitudes. Measures rate of convergence to stable distribution.

StructuredPopulationCore.sensitivity — Function
sensitivity(A::AbstractMatrix)

Sensitivity matrix: S[i,j] = v[i] * w[j] / dot(v, w) where v = reproductive value, w = stable distribution. With dot(v,w)=1 normalization, this simplifies to v * w'.

sensitivity(sol::AbstractProjectionSolution)

Sensitivity matrix from solution.

StructuredPopulationCore.elasticity — Function
elasticity(A::AbstractMatrix)

Elasticity matrix: E[i,j] = (A[i,j] / lambda) * S[i,j] Entries sum to 1.0.

elasticity(sol::AbstractProjectionSolution)

Elasticity matrix from solution.

StructuredPopulationCore.net_repro_rate_lagged — Function
net_repro_rate_lagged(P::AbstractMatrix, F::AbstractMatrix)

Net reproductive rate R0 for a time-lagged model where P acts on n(t) and F acts on n(t-1).

Uses the augmented fundamental matrix approach (Kuss et al. 2008):

  • U_aug = [[P, 0], [I, 0]] (survival/transition part of augmented system)
  • F_aug = [[0, F], [0, 0]] (fecundity part of augmented system)
  • Naug = (I - Uaug)^{-1}
  • R0 = ρ(Faug · Naug)

Returns Inf if the fundamental matrix is singular.

net_repro_rate_lagged(lag_kernels::AbstractVector{<:AbstractMatrix},
                      lag_structure::TimeLagStructure)

Generalized R0 for multi-lag models. Decomposes the augmented matrix into survival (Uaug) and fecundity (Faug) parts, then computes R0 via the fundamental matrix.

lag_kernels[1] is treated as the survival/transition kernel (U), and lag_kernels[2:end] as fecundity kernels at each lag.

StructuredPopulationCore.generation_time_lagged — Function
generation_time_lagged(P::AbstractMatrix, F::AbstractMatrix)

Generation time T for a time-lagged model: T = log(R0) / log(λ).

λ is computed from the augmented matrix [[P, F], [I, 0]].

StructuredPopulationCore.stochastic_growth_rate — Function
stochastic_growth_rate(sol::AbstractProjectionSolution; burn_in=0)

Stochastic growth rate: exp(mean(log(lambda_t))) for t > burn_in. Geometric mean of per-step growth rates on the log scale.

StructuredPopulationCore.is_ergodic — Function
is_ergodic(A::AbstractMatrix)

Test if matrix A is ergodic (irreducible and aperiodic/primitive). An ergodic matrix converges to a unique stable distribution.

StructuredPopulationCore.is_irreducible — Function
is_irreducible(A::AbstractMatrix)

Test if matrix A is irreducible. A non-negative matrix is irreducible if its associated directed graph is strongly connected. Equivalent: (I + |A|)^(n-1) has all positive entries.

StructuredPopulationCore.is_primitive — Function
is_primitive(A::AbstractMatrix)

Test if non-negative matrix A is primitive. A non-negative irreducible matrix is primitive iff it is aperiodic. Equivalent: A^(n^2 - 2n + 2) has all positive entries (for irreducible A).

StructuredPopulationCore.mean_kernel — Function
mean_kernel(sol::AbstractProjectionSolution)

Mean kernel matrix from a stochastic simulation. Returns the single matrix for deterministic solves.

Delay & Lag Utilities

StructuredPopulationCore.DelayGeneratorTerm — Type
DelayGeneratorTerm(lag, operator)

A shared delayed linear contribution for continuous-time generator formulations. The operator may be a matrix or a callable returning one.

StructuredPopulationCore.TimeLagStructure — Type
TimeLagStructure

Describes the lag structure of a projection model.

Fields

  • max_lag::Int: Maximum lag L (must be > 0). The augmented state has L+1 blocks.
StructuredPopulationCore.augment_population — Function
augment_population(n0::AbstractVector, lag_structure::TimeLagStructure)

Replicate a population vector into the augmented state format. All lag slots are initialized with a copy of n0.

Returns a vector of length (L+1) * length(n0).

StructuredPopulationCore.expand_lag_matrix — Function
expand_lag_matrix(lag_kernels::AbstractVector{<:AbstractMatrix}, lag_structure::TimeLagStructure)

Build the (L+1)m × (L+1)m augmented block matrix from a vector of kernel matrices, one per lag index (0, 1, ..., L).

Arguments

  • lag_kernels: Vector of matrices [K_0, K_1, ..., K_L] where K_k acts on n(t-k). Length must equal lag_structure.max_lag + 1.
  • lag_structure: TimeLagStructure specifying the maximum lag.

Returns

The augmented block matrix with kernel matrices in the top row and identity matrices on the sub-diagonal.

expand_lag_matrix(P::AbstractMatrix, F::AbstractMatrix)

Convenience for the common single-lag case (L=1): n(t+1) = P·n(t) + F·n(t-1).

Returns the 2m × 2m augmented matrix [[P, F], [I, 0]].

StructuredPopulationCore.extract_lag_components — Function
extract_lag_components(K_aug::AbstractMatrix, m::Int, lag_structure::TimeLagStructure)

Extract the component matrices from an augmented block matrix.

Returns

A named tuple (kernels=Vector{Matrix}, m=Int, lag_structure=TimeLagStructure) where kernels[k+1] is the matrix acting on n(t-k).

StructuredPopulationCore.area_under_curve — Function
area_under_curve(x, y)

Trapezoidal numerical integration of y over x.
